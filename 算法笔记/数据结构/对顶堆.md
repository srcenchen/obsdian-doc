使用大小堆去维护一个 **第 k 小** 的数
大顶堆是去维护小的那部分，小顶堆去维护大的部分。
大顶堆的大小要严格控制在 K 以及 K 以内。
同时可以解决输入流中位数问题，其实也就是 K 在变化。对于中位数问题，保证 大顶堆的大小 大于 小顶堆大小，并且最多相差1.

使用双堆（大顶堆和小顶堆）来动态维护**第 $k$ 小的数**以及**数据流的中位数**是非常高效且经典的算法技巧。它的核心思想是通过两个堆的“对顶”操作，把数据流一分为二。
###  双堆维护动态极值与中位数
#### 核心原理：对顶堆
将所有数据分成左右两部分：
- **左边（较小值部分）**：用大顶堆（max-heap）维护。堆顶是这部分的最大值。
- **右边（较大值部分）**：用小顶堆（min-heap）维护。堆顶是这部分的最小值。
### 💡 应用一：维护数据流中的第 $k$ 小的数
**控制策略：**
1. 保持大顶堆的大小**严格等于 $k$**（在元素足够的情况下）。
2. 大顶堆的堆顶，就是当前整个数据流中的**第 $k$ 小的数**。
#### 🛠️ 动态插入与维护逻辑
每次新来一个元素 `num`：
1. **盲目先入左堆**：先将 `num` 放入大顶堆。
2. **过滤较大值**：将大顶堆的堆顶（最大值）弹出，转手送入小顶堆。
3. **维持 $k$ 的大小**：如果大顶堆的大小小于 $k$（且小顶堆不为空），从小顶堆弹出一个最小值送回大顶堆。

``` cpp
class KthSmallest {
private:
    priority_queue<int> max_heap;                             // 大顶堆，存较小的 k 个数
    priority_queue<int, vector<int>, greater<int>> min_heap;  // 小顶堆，存其余较大的数
    int k;

public:
    KthSmallest(int k_val) : k(k_val) {}

    void add(int num) {
        // 1. 元素先过一遍大顶堆，再洗到小顶堆，确保两边有序
        max_heap.push(num);
        min_heap.push(max_heap.top());
        max_heap.pop();

        // 2. 保证大顶堆严格拥有 k 个元素
        if (max_heap.size() < k) {
            max_heap.push(min_heap.top());
            min_heap.pop();
        }
    }

    int getKthSmallest() {
        return max_heap.top(); // 大顶堆的堆顶即为第 k 小
    }
};
```

### 💡 应用二：数据流中的中位数（变动 $k$ 值）
中位数问题本质上是 $k$ 随着总数据量 $N$ 动态变化的特殊场景（$k = \lceil N/2 \rceil$）。
**控制策略：**
- 约定：**大顶堆的大小 $\ge$ 小顶堆的大小**，且两堆大小之差**最多为 1**。
- 如果总数 $N$ 是奇数，中位数在大顶堆的堆顶。
- 如果总数 $N$ 是偶数，中位数为两个堆顶元素的平均值。
#### 🛠️ 数据流中位数通用模板
``` cpp
class MedianFinder {
private:
    priority_queue<int> max_heap;                             // 左边：大顶堆
    priority_queue<int, vector<int>, greater<int>> min_heap;  // 右边：小顶堆

public:
    void addNum(int num) {
        // 核心：先去大顶堆走一圈，最大值洗到小顶堆
        max_heap.push(num);
        min_heap.push(max_heap.top());
        max_heap.pop();

        // 平衡机制：若右边比左边多了，从小顶堆挪回一个给大顶堆
        // 这样能确保：max_heap.size() >= min_heap.size()
        if (max_heap.size() < min_heap.size()) {
            max_heap.push(min_heap.top());
            min_heap.pop();
        }
    }

    double findMedian() {
        if (max_heap.size() > min_heap.size()) {
            return max_heap.top(); // 奇数个，左堆顶就是中位数
        }
        return (max_heap.top() + min_heap.top()) / 2.0; // 偶数个，取两堆顶平均值
    }
};
```

### 📌 复杂度与总结
- **时间复杂度**：插入新元素 `add()` 为 $O(\log N)$，查询极值/中位数均为 $O(1)$。相比于每次重排序的 $O(N \log N)$ 或是暴力插入的 $O(N)$，双堆是解决输入流（动态数据）极值问题的最优解法。
- **记忆口诀**：**多退少补，先过大堆再进小堆，左大右小控规模。**
