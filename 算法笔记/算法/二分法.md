### 二分法分为：二分查找 和 二分答案

### 1. 二分查找
核心思想：每次将问题的数量减半，直接废弃掉不可能存在解的区间。
#### 💡 开区间模板（最不易出错的写法）
保持开区间 $(left, right)$，循环终止条件固定为 `left + 1 == right`。此时 `left` 和 `right` 刚好把数组切分成两半。
``` cpp
// 返回第一个 >= target 的下标 (Lower Bound)
int lowerBound(vector<int>& nums, int target) {
    int left = -1, right = nums.size(); // (left, right) 开区间
    while (left + 1 != right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target)
            right = mid; // 答案在左侧或就是mid，收缩右边界
        else 
            left = mid;  // 答案在右侧，收缩左边界
    }
    return right; 
}

// 返回最后一个 <= target 的下标 (Upper Bound)
int upperBound(vector<int>& nums, int target) {
    int left = -1, right = nums.size(); // (left, right) 开区间
    while (left + 1 != right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] <= target)
            left = mid;  // 答案在右侧或就是mid，收缩左边界
        else 
            right = mid; // 答案在左侧，收缩右边界
    }
    return left; 
}
```
#### 📌 实例对比
对于数组 `nums = [1, 1, 1, 2, 2]`，设定 `target = 1`：
- `lowerBound` 返回 `0` —— 指向**第一个** `1` 的位置。
- `upperBound` 返回 `2` —— 指向**最后一个** `1` 的位置。
### 2. 二分答案（补充部分）
二分查找是在**数组**中找目标值；而**二分答案**是在解的空间（一个虚拟的有序区间）里找最优解。
- **核心特征**：题目通常求“最大值的最小值”或“最小值的最大值”。
- **关键步骤**：
    1. 确定答案的取值范围 `[min_ans, max_ans]`。
    2. 编写一个 `check(mid)` 函数，判断当前答案 `mid` 是否可行（通常是 $O(N)$ 的贪心或模拟）。
    3. 利用二分查找的模板，在区间内不断逼近最优解。
#### 🛠️ 二分答案通用模板
``` cpp
bool check(int x) {
    // 判断答案 x 是否满足题目条件
    // ...
    return true;
}

int binaryAnswer(int min_ans, int max_ans) {
    int left = min_ans - 1, right = max_ans + 1;
    while (left + 1 != right) {
        int mid = left + (right - left) / 2;
        if (check(mid)) {
            // 根据题目求最大还是最小，来决定移动 left 还是 right
            left = mid;  
        } else {
            right = mid;
        }
    }
    return left; // 或 return right，取决于具体题意
}
```
