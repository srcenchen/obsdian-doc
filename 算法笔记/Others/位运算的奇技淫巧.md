### 3. 作为集合来用 (状态压缩->多个状态压缩到一个状态上)
在数位DP、状态压缩的一些方面，会需要用到一个情况：
	给你一个集合 ``{1, 2, 3, 4, 5, 6, 7}`` 问 数字 i 是否在这个集合当中
我们当然优选``unorderedset``解决，但是我们要希望把这个集合存在一个memo记忆化数组呢？当作一个状态保存呢？貌似这么做不太合适。
#### 数据的存储原理
0 0 0 0 1 0 1 0 二进制数
7 6 5 4 3 2 1 0 位数
这组二进制数据，我们就可以认为集合内存在 1 和 3 这两个数字。
核心原理我们就是将第i位当作数字i,1代表存在，0代表不存在。
#### 集合保存
```cpp
int mask = 0;
// 插入 数字 3
// 先将数字1左移3位变成 100
// 在按位或，保留原有mask的值
mask = mask | (1 << 3);
```
#### 集合的查询，查询目标数字是否在集合内
```cpp
int mask = 0;
// 插入 数字 3
mask = mask | (1 << 3);
// 查询 数字 3
// 和插入相反，先将mask右移3位，将目标位置暴露在最右端
// 再按位与1 判断最右端是否为1,1则代表存在3这个数字
if ((mask >> 3) & 1) cout << "存在数字3";
else cout << "不存在！";
```
